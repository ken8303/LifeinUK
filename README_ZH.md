# Life in the UK Trainer（英國入籍考試練習程式）

專為 **Life in the UK** 英國公民入籍考試設計的練習程式。收錄 408 條完整題庫、17 套單元練習測驗，配備會優先抽考易錯題目的適應性學習引擎，以及完全模擬真實考試環境的計時測驗。

## 簡介

本程式專為準備 Life in the UK 考試的考生而設。全部 408 條題目按原廠 17 套練習測驗進行分類，每條題目均附有簡明扼要的答案解析與重點說明。

主介面採用繁體中文，而題目、選項及測驗控制按鈕均維持英文，以確保與官方正式考試語言環境完全一致。

- **408 條題目**，分為 **17 套練習測驗**（每套 24 題）
- 支援單選題、對錯題（True/False）及多選題（Choose two answers），完全貼合真實題型
- 每題均附帶簡明答案解析
- 支援一鍵將難題收藏至專屬的「弱項題庫」
- 完整**統計數據**：整體掌握率、408 題錯誤熱力圖、按章節與測驗劃分的正確率、歷次分數趨勢圖及可排序的單題表現表格

## 使用方法

1. 請使用電腦瀏覽器開啟 [https://eddiesung111.github.io/life-in-the-uk-trainer/](https://eddiesung111.github.io/life-in-the-uk-trainer/) 連結。
2. 建議由 **練習測驗**（Practice tests）開始，按順序完成第 1 至 17 套測驗。
3. 選取答案後按 **Submit answer**（提交答案）。未按提交前不會計分或顯示對錯，可隨時更改選項。按 **Next**（下一題）繼續。
4. 完成部分練習後，可使用 **適應性模擬**（Adaptive mock）— 系統會從 408 題中動態抽取 24 題，並大幅提高你經常答錯題目的出現機率。
5. 使用 **正式模擬考試**（Official simulation）進行考前實戰演練：24 題、45 分鐘倒數計時、提交前不顯示對錯，答對 18 題（75%）為合格。
6. 隨時查看 **統計**（Statistics）頁面，了解哪些手冊章節需要優先加強。

### 鍵盤快速鍵
- `1`–`4` 或 `A`–`D`：選擇答案選項
- `Enter`：提交答案 / 前往下一題
- `←` / `→`：切換題目
- `F`：考試中標記題目以供稍後覆核
- `Shift` + `B`：收藏 / 儲存題目至弱項題庫

## 模式說明

| 模式 | 功能說明 |
|---|---|
| **練習測驗** (Practice tests) | 按照官方結構分為 17 套測驗，每套 24 題。提交後即時顯示對錯與詳細解析。無時間限制，可自由前後切換題目。 |
| **適應性模擬** (Adaptive mock) | 根據個人歷史答題紀錄，從 408 題中動態加權抽取 24 題。每題答完即時顯示答案與解析，完成後顯示總分。 |
| **正式模擬考試** (Official simulation) | 完全還原官方考試環境：24 題、45 分鐘倒數計時（附帶少於 5 分鐘警示）、標記覆核功能、交卷前鎖定答案、交卷前總覽網格，以及 18/24 合格門檻評分與完整考後檢討模式。 |
| **弱項題庫** (Weak spots) | 收錄你手動收藏的題目，以及正確率低於 60% 或最近一次答錯的題目。可針對全部弱項或指定類別進行強化練習。 |
| **統計** (Statistics) | 包含全 408 題掌握率、錯誤熱力圖、按手冊章節與測驗統計的正確率、模擬考分數趨勢圖，以及可按正確率或答題次數排序的單題數據表。 |

> **「已掌握」定義：** 一條題目必須至少回答過兩次，且**最近兩次嘗試均答對**，才會被系統判定為「已掌握」。

## 適應性出題演算法

系統根據使用者對每條題目的正確率 ($r_i$)，利用柯西分佈（Cauchy / Lorentzian 密度函數）計算其被抽中的權重：

$$P(q_i) \propto \frac{1}{\gamma \cdot \left(1 + \left(\frac{r_i - x_0}{\gamma}\right)^2\right)}$$

其中 $\gamma = 0.35$，$x_0 = 0$。該機率密度在正確率為 0% 時達到峰值，並呈重尾衰減。因此，你從未答對過的題目被抽中的機率，約為經常答對題目的 **9 倍**；而已掌握的題目出現機率較低，但仍保持非零的被抽中機會。

正確率 $r_i$ 採用拉普拉斯平滑（Laplace smoothing）：

$$r_i = \frac{\text{correct} + 1.5 \times 0.55}{\text{attempts} + 1.5}$$

確保未曾作答的題目初始機率為 0.55。此外，系統會再套用四項動態調整因子：

| 因子 | 影響效果 |
|---|---|
| **近期表現 (Recency)** | 若最近 3 次嘗試均答錯，出現權重最高提升至 $\times 1.6$ |
| **冷卻時間 (Cooldown)** | 剛做過的題目權重暫時降至 $\times 0.35$，並在一小時內逐漸恢復至 $\times 1.0$ |
| **書籤收藏 (Bookmark)** | 收藏至弱項題庫的題目獲得 $\times 1.5$ 權重加成 |
| **重複過濾 (Dedupe)** | 同一次測驗中自動折疊題目文字重複的題型 |

不放回加權隨機抽樣採用 **Efraimidis–Spirakis 演算法**：每條題目計算鍵值 $-\ln(U) / w$（其中 $U \sim \text{Uniform}(0, 1)$，$w$ 為最終權重），並選取鍵值最小的 24 條題目。

## 資料儲存與環境要求

> **紀錄儲存：** 你的練習進度與統計數據均儲存在本地瀏覽器（`localStorage` / `IndexedDB`）。數據與特定裝置及瀏覽器綁定。若更換瀏覽器、使用無痕模式或清除瀏覽資料，進度將會重置。本程式無須註冊帳戶，亦不會上傳任何個人數據至伺服器。

> **僅支援桌面 / 手提電腦：** 正式考試於電腦終端機上進行，因此本程式介面針對螢幕寬度至少 $1024\text{px}$ 的桌面設備進行優化。
